# 净水器滤芯更换提醒系统 V3

一个用于跟踪和提醒客户更换净水器滤芯的 Web 应用程序,纯前端运行,无需后端服务器。

## 功能特点

### 账户
- **单机模式**(默认):数据只保存在当前浏览器;首次打开时创建管理员账户,之后可注册普通账户;支持安全问题找回密码。密码和安全问题答案以 PBKDF2 加盐哈希保存,不保存明文
- **云端模式**:同事用各自账号登录同一个网址,普通成员只能看到自己的客户,管理员看全部;账号由管理员在腾讯云开发控制台创建,数据权限由云端安全规则保证。部署步骤见 [DEPLOY.md](DEPLOY.md)
- 修改密码、管理员用户管理面板(提升 / 降级管理员)

### 客户管理(客户 → 装机记录)
- 一个客户下可以有多条装机记录(不同地址、型号或批次),每条记录单独计算滤芯提醒
- 客户信息:客户名称、省份、区域、是否长期合作、跟踪记录
- 装机记录:详细地址、联系人、联系电话、装机时间、型号、数量、安装位置、滤芯购买日期、更换间隔、备注、是否需要验水、是否有未收款、未收款间隔
- 添加记录时,客户名称与已有客户相同会自动归到该客户下
- 搜索(名称 / 联系人 / 电话 / 地址 / 型号),按区域、标记(未收款 / 验水 / 长期合作)、月份筛选
- 建议更换日期 = 最近一次换芯(装机时间、滤芯购买日期、换芯记录中最晚的一个)+ 更换间隔(留空默认 90 天)
- 换芯记录(每条装机记录)和跟踪记录(每个客户):添加、编辑、查看

### 提醒
- 仪表板:已到期 / 本周 / 本月 / 下月到期,以及待催收款,每组都可以导出
- 未收款催收:从最近一次跟踪(或销售日期)起,每隔"未收款自定义间隔"天(默认 30 天)提醒一次;添加跟踪记录时可以勾选"已收清款项"
- 通知中心(支持全部标记为已读)
- 登录后弹出今日提醒(超期 / 今日到期 / 待催款 / 本周概览),可"稍后提醒"

### 数据导入导出
- 导入导出格式与《格式样板》一致:19 列,一行一条装机记录
- 导入 .xlsx / .xls / .csv,兼容 WPS:自动识别表头,支持 `2011.9.9`、`23.10.11`、`2025-01-15`、Excel 日期等写法,也支持合并单元格
- 重复导入同一份表格会更新已有记录,不会产生重复记录;旧版 V3 导出的文件也能导入
- 导出 Excel(样板格式,电话保存为文本)、CSV、换芯记录明细
- 下载导入模板

#### 表格中两列"详情"的写法
- **最新跟踪记录详情**:每行一条,`日期 内容`,最新的写在最上面,例如 `2025.09.20 电话回访,下月安排换芯`
- **历史记录详情**:每行一条换芯记录,`日期|滤芯型号|数量|费用|操作人|备注`;也可以只写 `2024.3.7 更换2支`

## 使用方法

1. 克隆本仓库
2. 进入项目目录,运行本地服务器:
   ```bash
   python -m http.server 8000
   ```
3. 在浏览器中打开 `http://localhost:8000`

也可以直接用浏览器打开 `index.html`。

需要多人共用、换电脑也能看到数据时,按 [DEPLOY.md](DEPLOY.md) 部署到腾讯云开发,并在 `config.js` 中填写环境 ID。

## 示例数据

`examples/` 目录:
- `客户数据示例.csv`:当前导入格式示例(与《格式样板》相同的 19 列)
- `测试数据_V3格式.csv`、`测试数据_旧格式.csv`:旧版导入格式,用于测试兼容性

## 技术细节

- 前端:HTML5、CSS3、JavaScript
- 数据存储:单机模式为浏览器 localStorage;云端模式为腾讯云开发文档型数据库(`cloud.js`、`cloudbase/` 安全规则)
- Excel 解析:SheetJS 0.20.3,放在 `vendor/` 中,不依赖境外 CDN
- 单机模式下,数据只保存在当前浏览器中,不同设备之间不会同步,请定期导出备份
- 从旧版本升级时,原有数据会自动转换为"客户 → 装机记录"结构,旧数据原样保留在浏览器中作为备份
