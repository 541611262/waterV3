# 净水器滤芯更换提醒系统 V3

一个用于跟踪和提醒客户更换净水器滤芯的 Web 应用程序,纯前端运行,无需后端服务器。

## 功能特点

### 账户
- 用户注册和登录
- 带安全问题的密码找回
- 修改密码
- 管理员用户管理面板

### 客户管理
- 添加、编辑、删除客户
- 按客户名称、联系人或电话搜索
- 按区域、月份筛选
- 按时间正序 / 逆序排列
- 自动计算下次更换日期(支持自定义间隔,留空使用默认间隔)
- 滤芯更换历史记录:添加、编辑、查看

### 提醒
- 客户提醒仪表板:今日到期、本周到期、本月到期、下月到期,每组可单独导出
- 通知中心(支持全部标记为已读)
- 登录后弹出今日提醒(紧急提醒 / 今日到期 / 本周概览),可"稍后提醒"

### 数据导入导出
- 导入 CSV / Excel(.csv、.xlsx、.xls),兼容 Windows WPS
- 导出客户数据、历史记录详情
- 下载示例文件

## 使用方法

1. 克隆本仓库
2. 进入项目目录,运行本地服务器:
   ```bash
   python -m http.server 8000
   ```
3. 在浏览器中打开 `http://localhost:8000`

也可以直接用浏览器打开 `index.html`。

## 示例数据

`examples/` 目录:
- `客户数据示例.csv`:当前导入格式示例
- `测试数据_旧格式.csv`:旧版导入格式,用于测试兼容性

## 技术细节

- 前端:HTML5、CSS3、JavaScript
- 数据存储:浏览器 localStorage
- 每位用户的数据只保存在自己的浏览器中,不同设备之间不会同步,请定期导出备份
